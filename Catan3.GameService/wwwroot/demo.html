?? Catan Companion UI Demo

Preview all the different game state interfaces

?? Board Setup
Initial game setup phase where players can shuffle the board tiles and prepare for the game.
  • Shuffle board button
  • Simple interface
  • Game preparation controls
?? Settlement Placement
Interactive settlement placement during the allocation phase with vertex selection and tile picking.
  • Hexagon vertex selector
  • Tile number dropdown
  • Touch-friendly interface
  • Visual feedback
?? Supplemental Choice
Timed decision phase for expansion games where players choose whether to participate in supplemental building.
  • 10-second countdown timer
  • Do/Decline buttons
  • Auto-decline when timer expires
  • Progress indicator
?? Dice Rolling
Dice selection interface where players choose their roll result (2-12) and can play knight cards.
  • Number buttons 2-12
  • Knight card play button
  • Visual roll selection
  • Next disabled until roll
?? Purchase & Actions
Main gameplay interface with purchase options and action buttons, smart-enabled based on game rules.
  • Settlement, City, Road buttons
  • Smart enable/disable logic
  • Visual availability indicators
  • Special action buttons
?? Move Robber
Robber movement interface triggered by rolling 7 or playing a knight card.
  • Tile selection interface
  • Player targeting
  • Visual feedback
  • Confirmation controls

?? How to Test on Mobile

To test these interfaces on your phone or tablet:

  1. Ensure your mobile device is on the same WiFi network
  2. Use the network URLs shown when you start the service
  3. Click any state card above to see the mobile-optimized interface
  4. Test touch interactions, scrolling, and responsive design
